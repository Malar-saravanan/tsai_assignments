# TSAI Assignments 

This repository contains three mini-apps built as part of TSAI assignments:

## Session 1
### 1. Chrome Reading Saver Extension
A lightweight Chrome extension that automatically saves your scroll position and restores it when you revisit the same page, making reading long articles easier.

## Session 2
### 2. Image Filter App
A simple web app to apply various filters (grayscale, blur, brightness, etc.) to uploaded images using HTML, CSS, and JavaScript.

### 3. Animal App
An interactive app where users can choose between cat, dog, or elephant and upload files related to the selected animal category.

---
#### How to Run
Each app has its own folder. Open the respective folder and follow the instructions in its README or run the HTML file directly in a browser.
