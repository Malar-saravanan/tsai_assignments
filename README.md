### 📖 Reading Progress Saver - Chrome Extension
**Smart bookmark system for web readers**

A Chrome extension that saves and restores your reading progress on any website, ensuring you never lose your place again.

#### 🎯 Key Features
- **Selective Tracking**: Enable/disable tracking with floating ON/OFF button
- **Automatic Progress Tracking**: Saves scroll position as you read
- **Smart Restoration**: Restores reading position when you revisit pages
- **Visual Notifications**: Subtle popup notifications for progress restoration
- **Progress Management**: Popup interface to view and clear saved progress
- **Privacy-First**: All data stored locally in browser
- **Performance Optimized**: Lightweight and fast

#### 🛠️ Technology Stack
- **Platform**: Chrome Extension (Manifest V3)
- **Frontend**: HTML, CSS, JavaScript
- **Storage**: Chrome Local Storage API
- **Build**: Node.js + NPM scripts

#### 📁 Location
```
📂 chrome-reading-assistant/
├── src/
│   ├── manifest.json    # Extension configuration
│   ├── content.js      # Page interaction scripts
│   ├── background.js   # Service worker
│   ├── popup.html     # Extension popup
│   └── popup.js       # Popup functionality
├── scripts/           # Build scripts
└── README.md         # Detailed documentation
```
