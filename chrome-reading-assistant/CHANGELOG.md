# Changelog

All notable changes to the Reading Progress Saver Chrome Extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Keyboard shortcuts for quick actions
- Export/import progress data functionality
- Reading time estimation
- Dark mode support

### Changed
- Improved performance with better event handling
- Enhanced UI with modern design elements

### Fixed
- Memory leaks in long-running sessions
- Scroll position accuracy on dynamic content

## [1.0.0] - 2024-01-22

### Added
- Initial release of Reading Progress Saver
- Selective progress tracking with toggle functionality
- Floating toggle button on every page
- Automatic progress saving and restoration
- Beautiful popup interface for progress management
- Visual notifications for progress restoration
- Support for all websites
- Local storage for privacy
- Automatic cleanup of old entries
- Production-ready build system
- Comprehensive documentation

### Features
- **Selective Tracking**: Choose which pages to track
- **Smart Restoration**: Automatically restore reading position
- **Progress Management**: View and manage all saved progress
- **Privacy-First**: All data stored locally
- **Performance Optimized**: Debounced saving and efficient event handling

### Technical
- Manifest V3 compliance
- Service worker for background processing
- Content scripts for page interaction
- Modern JavaScript with ES6+ features
- Comprehensive error handling
- JSDoc documentation
- ESLint code quality checks
